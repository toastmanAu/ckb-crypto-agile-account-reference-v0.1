# Frontend ABI-v1 Vector Provenance

`frontend-v1.json` is generated by the consensus-byte-exact helpers in
`ckb-account-host`. It anchors the browser implementation to the same state,
witness, group-sighash, authorization-digest, and P256ProofV1 framing used by
the CKB contracts and VM suite.

Regenerate it from the repository root:

```sh
cargo run -p ckb-account-host --example export_frontend_vectors -- \
  vectors/frontend-v1.json
```

The exporter uses fixed public test data only. It parses or recomputes each
consensus structure before writing and contains no credentials or private
signing material.
